## 설치 방법

1. ZIP 전체를 새 폴더에 풉니다.
2. Xenia를 종료하고 **01_Patch_ISO.cmd**를 실행합니다.
3. 일본판 원본 ISO를 선택하고 완료될 때까지 기다립니다.
4. 생성된 새 한글 ISO를 Xenia에서 실행합니다.

원본 ISO는 보존하며, 작업 완료 후 임시 파일은 자동으로 정리됩니다. 오류로 중단되면 같은 원본 ISO로 다시 실행하세요.

문의 시 `files` 폴더의 `ISO_날짜.log`와 문제가 발생한 화면을 함께 확인해 주세요.
